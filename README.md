## 2. High-Level Technical Pillars (Public Overview)
* **Deterministic Memory Architecture:** Built entirely on Modern C++17 with zero dynamic memory allocation (`new`/`delete`), eliminating memory leaks and runtime fragmentation for maximum predictability.
* **Flight Dynamics & Orbital Stability:** Integrates high-precision numerical propagation models to maintain optimal trajectory alignment and aerodynamic efficiency under dynamic atmospheric conditions.
* **Radiation & Environmental Resilience:** Employs advanced architectural redundancy to mitigate Single Event Upsets (SEUs) from cosmic radiation, alongside temporal filtering mechanisms to screen out transient electrical interference.
* **Autonomous Fault Detection & Recovery (FDIR):** Features a structured state-machine hierarchy designed to gracefully handle environmental anomalies, execute safety abort protocols, and secure system states safely.
